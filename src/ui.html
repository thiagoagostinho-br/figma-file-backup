Backup de Arquivo

Exporta a estrutura completa do arquivo atual (paginas, camadas e metadados) para um arquivo JSON local.

Backup de Times / Projetos (via API)

Baixa o JSON completo de todos os arquivos dos times informados abaixo. Requer um Personal Access Token (Figma → Settings → Security → Personal access tokens). Drafts pessoais nao sao suportados: a API do Figma nao os expoe.

O ID do time fica na URL ao abrir o time no Figma: figma.com/files/team/<team_id>/...
O token fica salvo apenas neste arquivo/maquina (armazenamento local do plugin). Nao compartilhe este token com ninguem.
